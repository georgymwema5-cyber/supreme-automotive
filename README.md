# SUPRÊME AUTOMOTIVE

Site vitrine statique multi-pages pour SUPRÊME AUTOMOTIVE.

## Pages
- `index.html` — accueil
- `catalogue.html` — catalogue
- `vehicule.html` — fiche véhicule dynamique via `?car=phantom`, `?car=terra` ou `?car=velocity`
- `marque.html` — identité de marque
- `contact.html` — formulaire ouvrant l'application e-mail du visiteur

## Lancer en local
Ouvrir `index.html` dans un navigateur. Pour un aperçu plus fiable, servir le dossier avec un serveur statique local.

## Publier sur Netlify
Glisser-déposer le dossier du projet dans Netlify Drop, ou connecter le dépôt GitHub et utiliser :
- Build command : laisser vide
- Publish directory : `.`

## Personnalisation
- Couleurs et responsive : `style.css`
- Menu, fiches véhicules et formulaire : `main.js`
- Remplacer les images Unsplash dans `style.css` par les photos officielles des véhicules.

## Important
Les trois véhicules sont des concepts de démonstration et non des annonces réelles. Les prix, caractéristiques, disponibilités et coordonnées commerciales doivent être renseignés avant publication commerciale. Le formulaire utilise `mailto:` et nécessite un client e-mail configuré.
